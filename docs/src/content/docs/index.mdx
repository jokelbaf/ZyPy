```zig title="src/root.zig"
const std = @import("std");
const py = @import("zypy");

fn add(a: i64, b: i64) !i64 {
    return std.math.add(i64, a, b);
}

pub const module = py.module(.{
    .doc = "hello, written in Zig.",
    .functions = .{
        .add = py.function(add, .{ .doc = "Add two numbers." }),
    },
});

comptime {
    py.exportModule(module);
}
```

## What ZyPy does

<CardGrid>
	<Card title="Functions" icon="seti:zig">
		Export Zig functions with named parameters, defaults, `*args`, and `**kwargs`. ZyPy converts arguments and reports invalid calls as Python exceptions.
	</Card>
	<Card title="Classes" icon="puzzle">
		Define Python classes with Zig structs. Add fields, properties, operators, iteration, and inheritance.
	</Card>
	<Card title="Python objects" icon="seti:python">
		Work with Python lists and dicts, call Python functions, and access NumPy arrays and other buffers without copying.
	</Card>
	<Card title="Threads" icon="random">
		Release the GIL during long computations, call Python from Zig threads, or support free-threaded Python.
	</Card>
	<Card title="Packaging" icon="setting">
		Build Linux, macOS, and stable ABI wheels, along with source distributions. manylinux builds do not need Docker.
	</Card>
	<Card title="Embedding" icon="laptop">
		Run Python inside a Zig program and let it import Zig modules. You can ship Python with the program.
	</Card>
</CardGrid>

## Try it

With [uv](https://docs.astral.sh/uv/) installed, create a project and call its function from Python:

```sh
uvx zypy new hello
cd hello
uv run python -c "import hello; print(hello.add(1, 2))"
```
